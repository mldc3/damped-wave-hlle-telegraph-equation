# Numerical Methods

This portfolio is organized around the Practice 6 method set:

1. Explicit finite differences.
2. Matrix exponential time evolution.
3. Crank–Nicolson time evolution.
4. HLL/HLLE conservative flux formulation.

The repository keeps the uploaded Python source file unchanged in `src/damped_wave_telegraph_methods.py` and presents the uploaded animations in a structured layout by method and boundary-condition comparison.
