# Theory Background: Damped 1D Wave / Telegraph Equation

This document develops the theoretical background behind the numerical project implemented in this repository. The project studies a damped one-dimensional wave equation, also known in this context as a telegraph-type equation, and compares several numerical approaches for its solution: an explicit finite-difference method, a matrix exponential method, a Crank--Nicolson method and an HLL/HLLE conservative flux method.

The goal is not simply to animate a wave. The purpose is to understand how a physical equation is transformed into different numerical models, and how each numerical method affects propagation, damping, boundary reflections, phase accuracy and artificial dissipation.
