# Damped Wave / Telegraph Equation: Explicit, Crank–Nicolson and HLL Solvers

This repository will host a cleaned portfolio version of a computational-physics project focused on the damped one-dimensional wave equation (telegraph equation).

Planned content includes:

- the damped one-dimensional wave equation / telegraph equation,
- second-order wave dynamics,
- transformation to a first-order system,
- explicit finite-difference integration,
- matrix exponential time evolution,
- Crank–Nicolson time evolution,
- conservative flux formulation,
- HLL/HLLE approximate Riemann solver,
- Dirichlet and Neumann boundary conditions,
- numerical damping versus physical damping,
- CFL stability,
- numerical viscosity,
- performance and method comparison.

The original report, LaTeX notes, Python source code, and figures will be uploaded in later updates.
